## 已知限制

- 概要（summary）只在画布内生效，暂未写入 XMind 8 的 content.xml（边界、联系线、标签、标记已写入）。
- 矩阵 / 气泡图等少数骨架未实现（向右 / 向左 / 向下 / 双向 / 树状 / 时间轴 / 鱼骨 已支持）。
- 附件以链接或 data URL 内嵌（单个 ≤150KB），不支持大文件分片存储。
- 演示模式为逐主题放映，不含讲义导出与多屏演讲者视图。
- 后端不可用时：前端会拒绝非 JSON 的接口响应，避免把静态托管的 index.html 当成文档写回（数据安全兜底）。

## 排除项

- 多人实时协作、评论、@成员、共享链接权限、团队空间：按需求排除。
- 云同步 / 移动端 / 桌面客户端：不在本项目范围。
