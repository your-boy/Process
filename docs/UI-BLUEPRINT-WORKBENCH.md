# Blueprint Workbench · UI 改造记录

> 风格方向：C（工程蓝图 / Raw）+ A（中性工作台）混合。
> 目标：去模板化、提高信息密度、建立模式识别、减少滚动。

## 设计语言

- 暖纸底 `#f3f1ea`，墨黑文字，1px 细线，弱阴影。
- 圆角统一收紧：输入/按钮 4px，面板 6–8px。
- 标题使用衬线体，元数据使用等宽字体，正文/控件使用系统无衬线。
- 模式功能色：
  - 绘图 `#2f5bff`
  - 思维导图 `#7c5cff`
  - Markdown `#b45309`
  - 思维笔记 `#2f6f5e`
- 背景有极淡的 32px 工程网格，卡片/面板保持不透明。
- 暗色主题使用石墨底 + 提亮后的模式色。

## 页面改动

### 登录 / 重置密码

- 视觉标题移除（保留无障碍标题）。
- 左侧标签 + 右侧输入；登录 / 记住密码 / 忘记密码同一行，重置 / 返回登录同一行。
- 表单字段统一为“左侧标签 + 右侧输入框”：修改密码、文件名重命名、思维导图任务日期均采用同一对齐方式；
  表格参数和节点属性原本已是左右并排，不重复改动。
- 硬边偏移阴影 + 顶部墨线，去掉通用白卡片悬浮感。

### 工作区

- 顶部保留品牌、返回入口、描边式“+ 新建”按钮和账户操作；文件搜索框、类型筛选与“查询 / 重置”紧跟在“新建”右侧，
  另外常驻批量删除、视图切换；中文界面完整显示中文占位符与按钮，不回退到原始 i18n key。
- 类型筛选包含全部类型、绘图、思维导图、Markdown、思维笔记，卡片和列表视图同步生效。
- 列表视图提供标题、类型、摘要、页数四列表头；点击表头按该列升序排序，再次点击切换为降序，当前排序列显示方向箭头。
- 文档架 4 列（1600）/ 3 列（1280），卡片只保留一个内容区。
- 模式色条 + 模式徽章 + 文档标题合并到卡片顶部，删除底部重复标题/摘要。
- 默认文档标题与模式名相同时隐藏模式徽章，进一步减少重复。
- 预览区按模式轻微着色；已保存文档不显示状态徽章。
- 文件卡片支持右键上下文菜单，和省略号菜单一致：打开 / 重命名 / 删除；菜单跟随鼠标位置并自动收进视口。
- 工作区支持 `Ctrl/⌘ + 左键拖动`框选多张卡片，也支持 `Ctrl/⌘ + 单击`逐张加选；顶部常驻
  已选数量与“批量删除”，无选择时按钮禁用，选中后出现“取消选择”。
- 选中卡片左上角显示实心打勾徽标，卡片同时加深边框，明确标识选中文档；点击打勾徽标或再次点击已选卡片
  可单独取消该文档，不需要先清空整批选择。
- 工作区支持卡片 / 列表两种视图，通过顶部分段开关切换；列表行显示标题、模式、摘要和页数。
- 工作区分页默认根据浏览器可视高度计算每页数量，分页选择器直接显示计算出的具体页数，
  不再显示抽象的“自动”；卡片视图按可用列数 × 完整可见行数，列表视图按完整可见行数。
- 底部分页栏左侧提供每页数量选择：10 / 20 / 40 / 60 / 100，并显示当前视口计算值；手动选择后
  保存到本地存储并在刷新后保留，切换视图仍生效。
- 手动分页数量超出可视区域时，文档架内部滚动，顶栏和分页栏保持固定，整页不产生多余滚动。
- 文档卡片与列表均显示数据库持久化序号（如 `#095`）；序号由后端按用户分配并写入 `diagram.sequence_no`，
  历史数据启动时自动回填，删除文档不会重排已有序号。列表表头支持按序号排序。
- 多页文档卡片底部显示页码切换器：`‹ 1 2 ›`，可直接切换缩略图预览页，不会误打开文档。
- 缩略图同时渲染节点、连线和思维导图/思维笔记文本块；只有文本块而没有图形的页面也不会误判为“空白”。

### 编辑器

- 顶层顶栏新增返回箭头；Process 品牌也可点击返回文件列表。
- 编辑器工具栏不再放导出/导入/保存/历史按钮，这些动作全部收进右键菜单；流程图/Markdown 下不再渲染空工具栏。
- 页签使用等宽小字号，活动页用蓝色下划线。
- 画布/右侧面板改为 1px 边框、无重阴影；面板标题使用等宽大写/字距。
- 右侧属性栏移除“大纲”和“图层”两个低频面板（所有模块统一移除）；思维笔记双栏视图里的
  左侧大纲属于正文导航，保留。
- 节点文字浮层改为可换行文本域：宽度随内容自动扩展（上限 560px），高度按行数增长，
  长文本完整显示；浮层始终限制在画布可视范围内。
- 编辑状态下仍可直接按住浮层拖动节点：按住后移动超过阈值会先提交当前文字，再进入节点拖动；
  原地点击仍保持文字编辑。
- 画布交互：空白处左键拖动 = 平移；Shift+左键拖动 = 框选；Space+左键/中键仍可平移。
- 流程图画布支持两种连线：从连接点按住拖到目标节点；或单击连接点进入待连接状态，再点目标节点完成。
  Esc、点击空白处或再次点源节点可取消。
- 思维导图拖动只移动当前主题：子主题的 `offsetX/offsetY` 不再反向带动父主题居中，
  因此拖一个叶子主题时，连线另一端的父/兄弟主题保持原位。
- 思维笔记画布中，未进入编辑的文本块可直接按住块体拖动；编辑中可通过块顶部拖动条移动。
- 节点选中后顶部新增旋转手柄，按住拖动即可旋转，和缩放手柄同一套视觉语言。
- 流程图节点属性抽屉和右键菜单提供“重置大小”，按该图形类型的默认宽高恢复（如矩形 176×68、判定 176×96）。
- 画布右键菜单集中了：保存、历史、导出、导入、插入样式（矩形/判定/文本块/子主题/同级主题）、
  粘贴、新建节点、全选、适应画布、网格、清除参考线、快捷键选项。
- Markdown 改为单面板：编辑 / 源码切换，可视化编辑器本身就是预览，不再单独占一栏预览。
- Markdown 编辑框右键提供文字样式、标题/列表、表格/分隔线/链接、文件操作和快捷键选项。
- 链接按钮并入 Markdown 格式工具栏，点击后才展开链接输入浮层。
- Markdown 表格按钮改为弹出式面板：插入前选择行数/列数（默认 2×2），表格内可继续减行/加行、
  减列/加列、删除表格；表格宽度上限 560px、单元格紧凑，不再默认铺满整页。
- Markdown 代码块选中后显示“属性”入口，支持编码语言、背景色、文字色、边框色/宽度、圆角、
  内边距和自动换行；语言在代码块右上角显示，属性写入 fenced-code info 字符串，源码切换、刷新和导入导出后仍保留。
- 代码块按语言进行低光语法高亮：关键字、字符串、数字、类型、函数、注释、属性等使用不同颜色；
  纯文本语言不套用语法颜色。代码块背景只绘制一次，`code` 子元素透明，避免选中时出现双层底色。
- 点击正文编辑器任意位置会关闭代码块/表格/链接属性浮层；再次点击“属性”时，浮层字段读取当前光标
  所在代码块的语言与样式，不会沿用上一个代码块的值。
- 代码块支持 `Ctrl + 左键` 拖动重排：可拖到其他代码块或普通正文块的上/下方；右侧、底部和右下角提供
  普通左键即可拖动的缩放手柄，也可在属性浮层直接填写宽度/高度。宽度、高度写入 fenced-code info 的 `w/h`。
- 表格列宽可直接拖拽：鼠标移到列边界会出现竖向蓝色手柄和 `col-resize` 光标，拖动即调整列宽；
  最右侧外边框也可拖动，用于直接改变整张表宽度。
- 表格面板提供行高、左/中/右对齐、上移表格/下移表格；第一列宽度通过其右侧列边界调整，
  左侧位置通过对齐方式控制。表格激活时工具栏常驻 `↑ / ↓` 快捷按钮，直接与前后段落交换位置；
  无可交换段落时按钮禁用。
- Markdown 编辑区与源码区均可滚动；导出所需的 HTML 预览改为屏幕外隐藏节点，仅用于 PNG/PDF 导出。
- 打印预览顶部工具栏拆分两个并排按钮：`打印` 与 `PDF`；`PDF` 直接生成并下载 `.pdf` 文件，
  不再打开系统打印窗口。
- 画布右键文件菜单同样拆分：顶层 `打印` 打开打印预览；`导出` 子菜单中的 `PDF` 直接下载 PDF 文件。
- 编辑器视图取消 1560px 内容宽度上限，左右仅保留 12px 安全边距；画布宽度随浏览器窗口变化。
- Markdown 编辑区和画布共用同一套视口高度：编辑器外壳 `100dvh - 80px`，工具栏和页签固定，
  画布/编辑区吃掉剩余高度；`ResizeObserver` 在容器尺寸变化时同步刷新标尺和浮层。
- 画布使用 `preserveAspectRatio="xMidYMid meet"`：画布容器铺满可视区，页面内容（节点/网格/参考线）
  等比缩放并完整居中显示，不拉伸节点。
- 思维笔记块、属性抽屉、右键菜单、导出菜单统一同一套边角和阴影语言。
- 属性抽屉按钮禁止中文逐字换行：文本块操作使用“缩进 / 取消缩进 / 删除”短标签，
  完整说明放在 `title`；抽屉横向溢出固定为 0。
- 清理冗余提示：文本块顶栏不再显示“拖动文本块”文案，新建思维笔记不再带示例句；
  笔记/历史空状态保留“暂无笔记 / 暂无历史版本”等状态词。
- 空白画布与空白文档缩略图不显示任何可见提示框、文字或模式分类；空白本身就是正常状态。
  仅保留读屏可访问的隐藏“空白”状态，列表摘要列使用 `—` 表示无内容。
- 其他冗余提示同步移除：画布空状态下的操作教程、关系线操作 toast、图形悬停描述、
  新建弹窗标题栏拖动提示。
- 单节点选中不再插入一整行快捷样式条，样式统一放在右侧属性抽屉；多选工具条改为单行横向滚动，
  避免工具栏换行把画布向下挤。
- 思维导图“搜索主题 / 标签 / 备注”工具组靠左排列，支持标签文本与“标签”筛选，并提供常驻“重置”按钮。
- 选中连线时，右侧属性抽屉显示连线标签、起点/终点、预设、路线、线型、箭头、颜色，
  并提供“编辑标签 / 删除连线”；不再出现空白属性面板或 `editor.edgeLabel` 原始键名。
- 1280×720、1280×800、1600×1000 均无整页滚动，节点/文本块位于视口内。

## 回归结果

```text
全量 E2E：49 passed
Vitest：  15 files / 90 tests passed
构建：    vite build 成功
```

格式溢出检查：

- 1280×720：四个模块 `scrollHeight === innerHeight === 720`，
  `scrollWidth === innerWidth === 1280`，画布高度 ≥ 300px。
- 1600×1000 编辑器：`scrollHeight === innerHeight === 1000`
- 1280×800 编辑器：`scrollHeight === innerHeight === 800`
- 登录、工作区、Markdown、思维笔记、暗色主题截图均确认无横向溢出。
- 节点文字浮层长文本：`scrollWidth <= clientWidth + 1` 且
  `scrollHeight <= clientHeight + 1`，无横/纵向截断。
